5 条关键架构决策
  • 关注点分离：Agent Router 决策 "走哪个 Agent"，LLM Planner 决策 "怎么执行"，避免选择与执行耦合。
  • 多层工具接入：原生 Tool Registry + Skills 与外部 MCP Servers 共存，统一适配映射。
  • Checkpoint vs Memory：Checkpoint Store 管理短期执行快照；Memory Service 管跨 session 知识，role/user/binding 三层 namespace。
  • 降级优先稳定性：QPS 限流 + 熔断 + 超时 + 服务回退，防止 Agent 模式对下游放大调用导致雪崩。
  • 可插拔 Router 策略：单 Agent / 规则路由 / 动态路由可热切换，主流程零侵入。

TAKEAWAYS

AI Coding 给事业群带来的 6 点启示

从数据出发，给一线研发与管理者的可落地经验。
1

个人独立闭环成为可能

过去需要 2~3 人协同（前端 + 后端 + 配置）才能交付的中等复杂业务，现在 1 个全栈工程师 + AI Agent 即可完成全栈交付，沟通成本几乎归零。

2

commit 颗粒度变细，可追溯性变强

日均 32 次提交不是"水 commit"，而是 AI 驱动下"想清楚 → 写一小段 → 自审 → 修正"形成的最小可回滚单元。回滚和 Bisect 成本大幅降低。

3

文档与代码同步产生

692 份 docs/.coord 文档随代码沉淀，研发"黑箱"变白盒。新人接手 / 跨团队对齐 / 离职交接都不再依赖会议或口口相传。

4

分支策略从"多版本并行"回归"主干推进"

旧仓 36~49 条分支并发治理成本高。AI Coding 把节奏从"版本驱动"切到"任务驱动"，4 条分支就足以管理 70 天高强度迭代。

5

突发能力提升，月度产能可达 900+ commits

agent-platform 在 2026-04 单月产出 920 commits，4 月+5 月共 1,789 commits。过去一年里整个 wisdom-vault 团队最高产月份才 221（2025-04）。

6

"高级工程师"角色升级为"Agent 团队负责人"

从写代码到写 Prompt + 评审代码 + 设计协作协议。.coord/decisions 中的 D001~D003 三个 AI Agent 协作协议，本质是新型工程治理资产。
