统计口径

本报告统计“有效代码行”：排除空行、常见整行注释和常见块注释；排除文档、历史 HTML 报告、图片、PDF/DOCX、lock 文件、依赖目录、缓存目录和构建产物。

查看纳入和排除规则
  • 纳入：Python、JavaScript、TypeScript、Shell、YAML、JSON、TOML、SQL、Dockerfile、Env、少量实际应用 HTML。
  • 排除：README、Markdown 设计文档、docs 目录、artifacts、diagrams、node_modules、.venv、dist、playwright-report、test-results、.coord、.octo、.claude、缓存目录和 lock 文件。
  • 模块边界：services/*、packages/*、agents/*、skills/* 按二级目录拆分；deploy、scripts、tests、stitch、.github 和 root 作为独立模块。
